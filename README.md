# 🍪 KUS — облік для бренду печива

Програма «як Poster», але під ваш цех печива: техкарти, автоматична собівартість, каса, звіти по прибутку та AI-помічник на базі Claude.

## Що вміє

| Розділ | Що там |
|---|---|
| **🧾 Каса** | Натискаєте на печиво → чек → «Пробити продаж». Знижка, спосіб оплати, коментар, можна вказати іншу дату. Зверху — виручка й прибуток за сьогодні. |
| **📊 Звіти** | Виручка, собівартість, валовий і чистий прибуток, кількість, середній чек — за сьогодні / вчора / тиждень / місяць / рік / весь час / свій період. Графік по днях (або місяцях), топ товарів, оплати, витрати за категоріями. |
| **📋 Техкарти** | Склад, вихід (шт), втрати %, пакування «на 1 шт», додаткові витрати (електрика тощо). Миттєво рахує собівартість замісу й 1 шт, маржу, націнку, food cost і **рекомендовану ціну** під вашу цільову маржу. Набори (box) складаються з інших техкарт. |
| **🧈 Інгредієнти** | Ціна упаковки → ціна за кг/л/шт. **Змінили ціну на борошно — всі техкарти перерахувались автоматично.** Історія цін і список техкарт, де використовується інгредієнт. |
| **🛍️ Продажі** | Історія чеків з фільтром по періоду; будь-який продаж можна відредагувати або видалити. |
| **💸 Витрати** | Оренда, реклама, обладнання… Віднімаються від валового прибутку → чистий прибуток. |
| **✨ AI-помічник** | 1) **Чек / список покупок** текстом або **фото** → AI розпізнає позиції, зіставить з вашими інгредієнтами й оновить ціни. 2) **Середні ціни у вашому місті** — AI шукає в інтернеті (Сільпо, АТБ, Metro, Zakaz.ua…). 3) **Рецепт текстом → готова техкарта** (сам переведе склянки/ложки в грами). 4) **Аналітик** — питайте про ваші цифри: «яке печиво найменш вигідне?», «яку ціну поставити на box з 6?». Перед збереженням ви завжди бачите й можете виправити результат. |
| **⚙️ Налаштування** | Назва, колір і логотип бренду, валюта, місто, цільова маржа, API-ключ, резервна копія (JSON), експорт продажів у Excel (CSV). |

Важливо: собівартість **фіксується в момент продажу**. Якщо згодом подорожчає масло — старі звіти не «попливуть», а нові продажі вже рахуватимуться за новою ціною. (У редагуванні продажу є кнопка «Підставити поточну собівартість», якщо треба.)

## Як запустити

### Варіант 1 — просто відкрити файл
Скачайте [`release/KUS.html`](release/KUS.html) і відкрийте в Chrome / Safari / Edge. Все. Працює і на телефоні.

### Варіант 2 — власний сайт на GitHub Pages (зручно з телефона)
1. Злийте цю гілку в `main`.
2. У репозиторії: **Settings → Pages → Source: GitHub Actions**.
3. Після кожного пуша в `main` сайт оновиться сам: `https://<ваш-логін>.github.io/KUS-business-/`.
4. На телефоні: «Поділитися → На екран “Додому”» — буде як додаток.

### Варіант 3 — для розробки
```bash
npm install
npm run dev      # локальний сервер з автооновленням
npm test         # тести розрахунків і AI-запитів
npm run release  # зібрати release/KUS.html
```

## Як увімкнути AI
1. Зареєструйтесь на [console.anthropic.com](https://console.anthropic.com), поповніть баланс (кілька доларів вистачить надовго) і створіть API-ключ.
2. Вставте ключ у **Налаштування → AI**.
3. Модель за замовчуванням — Claude Opus 5.5 (найрозумніша). Якщо хочеться дешевше — Sonnet 5.5 або Haiku 5.5.

Ключ зберігається тільки у вашому браузері й надсилається лише в Anthropic. Не вводьте його на чужих комп’ютерах. Резервна копія JSON ключ **не** містить.

## Де зберігаються дані
У браузері на вашому пристрої (localStorage), автоматично після кожної зміни. Тому:
- **робіть резервну копію** (Налаштування → «Резервна копія») хоча б раз на тиждень;
- щоб перенести дані на інший пристрій — експортуйте копію там, де вони є, і відновіть там, де потрібно;
- різні браузери/пристрої мають окремі дані.

При першому запуску завантажуються демо-дані (3 печива + набір). Видалити: Налаштування → «Почати з чистого аркуша».

## Структура коду
```
src/calc.js        — уся математика: собівартість, маржа, періоди, звіти (без React, покрита тестами)
src/store.js       — стан, автозбереження, демо-дані, історія цін
src/ai.js          — інтеграція з Claude (Anthropic SDK): чеки, рецепти, пошук цін, аналітик
src/pages/*.jsx    — екрани
tests/             — node:test
```
